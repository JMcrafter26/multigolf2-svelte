About Multigolf Über Multigolf

Multigolf is a fun and unique tabletop game that doesn't require any preparation, sets, or extra materials. By using the participants' phones as the game table, people are forced to focus and are able to build a tangible course that intuitively makes sense. Participants don't just play a mini-golf game on some connected phones; they also construct their own levels in real life. Multigolf ist ein spaßiges und einzigartiges Brettspiel welches keine Vorbereitung, keine extra Materialien und keine gekauften Inhalte benötigt. Indem die Geräte der Spieler als Brett benutzt werden, werden alle dazu gezwungen, sich voll auf das Spiel zu konzentrieren. Man spielt nicht nur irgend ein Online-Minigolf Spiel zusammen, man spielt ein physikalisches Brettspiel bei dem man eigene Kurse und Level bauen muss.

How the Game works Wie das Spiel funktioniert

Every Multigolf game kicks off by connecting phones to the host device, which is simply the first device to start a game that the others can join. Next, you’ll build your course in real life by connecting the phones, drawing lines between them to create a fun and exciting mini-golf course that might feature obstacles and other cool surprises. Then, depending on the chosen game mode, you’ll be able to shoot balls between phones into holes! The phones connect wirelessly, providing a seamless interface that crosses phone borders and delivers a fun and satisfying experience! Jedes Minigolf Spiel startet damit, dass sich alle teilnehmenden Geräte mit dem Server-Gerät verbinden müssen. Das Server-Gerät ist das Gerät, auf dem das Spiel gestartet wird. Danach wird ein Kurs mit den Geräten gebaut, bei dem Geräte miteinander verbunden werden und Hindernisse, Start-Punkt und Löcher platziert werden können. Je nach ausgewähltem Spielmodus werden dann Bälle irgendwie in die Löcher geschossen! Die Verbindung zwischen den Handys erfolgt kabellos und funktioniert in den meisten Fällen ohne eine Verbindung über externe Server, sondern nur von Handy zu Handy direkt (Peer-To-Peer). Dies ermöglicht superschnelle Verbindungen die ermöglichen, dass Bälle fast ohne Merkbare Probleme von Display zu Display flitzen!

Development and Hosting Entwicklung und Hosting

Multigolf started as a Hackathon project, but it's now rebuilt and developed by me, Noel Friedrich! The game itself doesn’t require much compute power—there’s no central golfing server hosting the games: everything revolves around the host device, which connects directly to the players' phones via mostly peer-to-peer connections. This setup enables speedy communication between devices (crucial for those satisfying screen-to-screen ball shots) and drastically cuts down the cost of running this site! Multigolf ist als Hackathon Projekt am Trinity College in Dublin gestartet. Es ist nun jedoch neu gebaut und entwickelt von mir, Noel Friedrich! Das Spiel an sich benötigt keine großen Server im Hintergrund, weil die Spiele von den Geräten selbst gehostet werden (deshalb ist es auch nötig, ein Server-Gerät zu haben). Manche Handys/Geräte (besonders oft iPhones) wollen aber keine Peer-To-Peer Verbindung aufbauen, weshalb manchmal sogenannte "Relay-Server" dazwischengeschaltet werden müssen, über die die Daten fliegen. Da aber die meisten Daten zwischen den Handys direkt fliegen kostet das Hosten dieses Spiels nicht viel Geld und kann von mir privat betrieben werden!
